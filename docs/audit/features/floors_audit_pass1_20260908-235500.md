## 5. End-to-End Dependency Mapping

The full flow traces across:
Page (apps/web/src/app/(admin)/floors/[id]/edit/page.tsx)
  -> Concurrent Data Fetching:
     1. GET /floors/:id (Floor document)
     2. GET /floors/:id/rooms (Enriched rooms list + tenant names + floor occupancy stats)
     3. GET /floors (All existing floors for building stack preview + real-time collision check)
     4. GET /app-config (Amenity definitions with isPerFloor=true)
  -> State & Form Management (React Hook Form + Zod inline validation + dirty tracking)
  -> API Layer (PUT /floors/:id with stripped totalRooms)
  -> Database (MongoDB Floor collection updated; ServiceStatus preserved; audit log written)
  -> Navigation & Feedback (Toast success notification + redirect to /floors or /floors/:id)

## 6. Prioritized Implementation Work

### P0 — Critical Functionality & Collision Prevention
- Implement real-time floor number collision detection on client against existing floors (preventing raw 409 conflict errors).
- Fix dark mode contrast in FloorStackPreview by replacing raw -50/-700 classes with --badge-*-* tokens.

### P1 — Missing Operational Telemetry & Entity Connections
- Fetch and display enriched floor operational stats (Occupancy Rate, Active Rooms, Total Beds, Potential Revenue) via `GET /floors/:id/rooms`.
- Render live Room Roster directly on the Edit Floor page, showing room numbers, sharing types, occupancy status, and direct links to `/rooms/:id`.
- Add header quick actions: "View Floor Details", "Add Room to Floor", and "Floor Services".

### P2 — Major UX/UI Rebuild of Floor Edit & Create Surfaces
- Transform `/floors/[id]/edit` into an executive Floor Management Workspace:
  - Executive StatCard metric ribbon (Occupancy %, Active Rooms, Revenue, Beds).
  - Quick Floor Label Presets ("Ground Floor", "1st Floor", "2nd Floor", "Mezzanine", "Penthouse").
  - Rich 2-column layout pairing the edit form with the live Building Stack Preview.
  - Active room inventory list with status indicators and 1-click navigation.
  - Deletion/Restructure safety advisory explaining room/machine constraints.
- Rebuild `/floors/new` with matching executive aesthetics, preset buttons, and building elevation preview.

### P3 — Refinement & Polish
- Ensure all interactive cards and stack preview items use `var(--border-color-hover)`.
- Add unsaved changes indicator and dirty state confirmation.
