## 10. Implementation Tasks (ready for execution, no ambiguity)

1. List summary StatCards: Total assets, Low stock (warning variant, click -> low mode), Service due 30d (brand variant, click -> due mode), Retired (neutral). Data: reuse existing page fetch + banners endpoints; no new API.
2. Build ui/AssetVisuals.tsx: AssetStockMeter ({quantity, threshold}) with ok/low/untracked states, theme tokens only; used by list Qty cell, detail Inventory card, new/edit preview panels.
3. List Floor/Room columns: render populated floorId (label/floorNumber) and roomId (roomNumber + deep-link); row type extended with optional populated shapes; no API change.
4. Build assetCategoryIcon + ASSET_CATEGORY_LABELS in ui/AssetVisuals.tsx: furniture Armchair, appliance Refrigerator, electronics Plug, cleaning SprayCan, other Package; used by list Category cell, detail Identification card, new/edit category Select helper + preview.
5. New page 2-column layout (lg:grid-cols-[1fr_320px]): form left, sticky live preview right (category icon + name/location, AssetStockMeter from watched qty/threshold, next-service date line, floor/room selection summary). Watch via useWatch; preview is read-only.
6. Post-save routing: new -> /assets/:id of created record (POST returns data with _id/id); edit -> /assets/:id. Fall back to /assets when id absent.
7. Detail 'use client': add directive line 1 of assets/[id]/page.tsx (uses useState/useEffect/useParams/useRouter).
8. Detail timestamps: structured DetailCard (History icon) with Created/Updated rows instead of plain paragraph.
9. Build AssetServiceTimeline in ui/AssetVisuals.tsx: 3-node stepper (Purchased, Last serviced, Next service) + retired terminal note; overdue highlights danger; used by detail Dates card (below tiles) and edit context panel.
10. Edit page 2-column layout (lg:grid-cols-[1fr_320px]): form left; sticky context right (status badge, AssetStockMeter from loaded record, AssetServiceTimeline from loaded dates, floor/room links, retired-terminal hint when status retired).
11. Edit danger zone: DetailCard danger variant with Retire button + ConfirmModal (DELETE assets/:id -> /assets); hidden when already retired.
12. Keep portal boundaries: no Next tenant/guardian routes; no API source imports in web; no Flutter changes; no theme rewrites (token-pure components render in all 4 presets); sidebar untouched.
