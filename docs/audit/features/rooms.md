### 2. What the operator is doing here

The operator keeps the bed map of the building true: which bed of which room is free, who sleeps in
it, and what happens to a resident when their bed moves. The money belongs to the invoice module and
the payments module; what this module owns is the room, the bed and the resident in it. Done looks
like: every bed of every room is either taken by a named resident or marked free, a room that
depends on a broken amenity has told its residents, and a bed that moved is written on the record of
the resident who moved.

### 4. The contract

`packages/types/src/contracts/rooms.ts` now holds the grid of the domain (the room model has no
status field, so the grid is the service state of the amenities times the occupancy times the sharing
type times the active flag), one truth entry per action the admin can take (put a resident in a bed,
change the sharing type, create a room, edit a room, mark an amenity as degraded or down, take a
room out of service, rebuild the bed map, read the beds), the layout archetype with the grammar
tokens and the module own number, and the next best action per grid cell and per empty state.

The contract names what the code really has, including the places where a person is still not told:
a bed move, a bed that moved because the sharing type changed, a room that goes out of service and a
rebuild of the bed map of the building all reach nobody.

### 5. What was NOT done

- No API route, model or shared type was changed. Every gap that needs one is listed above as still
  open.
- The mobile portal was not touched. The resident half of this module (the room and the bed the
  resident reads on their phone) was not re-audited in this pass.
- The shared components were not changed. The bed assignment modal
  (apps/web/src/components/admin/QuickBedAssignModal.tsx) is no longer used by the room page, because
  it promised the resident an app update the server does not send; the room page carries its own
  bed move instead. The modal itself is still in the repository and is now unused.
- No screenshot and no browser run: every layout claim is read out of the component geometry and the
  width rule, not measured.
